# Arsan Gaz ERP V9.0.0 P1

İlk V9 üretim çekirdeği:

- Yalnızca NVIDIA NIM sağlayıcısı
- Varsayılan model: `deepseek-ai/deepseek-v4.1-flash`
- API anahtarı yalnızca `ARSANGAZ_NVIDIA_API_KEY` ortam değişkeninden okunur
- OpenAI uyumlu `/v1/chat/completions` ve `/v1/models` uçları
- Timeout, iptal, HTTP durum ve token kullanımı desteği
- Microsoft 365, veritabanı ve AgentWatcher hazırlık raporu
- API anahtarı kaynak koda, loga veya Git deposuna yazılmaz

Bu paket UI entegrasyonundan önce derlenebilir üretim servis temelini kurar.
