# Arsan Gaz ERP V2 Düzeltilmiş Kaynak

1. ZIP'i ayrı klasöre çıkarın.
2. İlk test için KUR_VE_CALISTIR.cmd dosyasını çalıştırın.
3. EXE üretmek için EXE_OLUSTUR.cmd dosyasını çalıştırın.
4. Üretilen uygulama publish\ArsanGazERP.exe konumunda olur.
5. Uygulamada Microsoft Giriş ve İzinleri Yenile işlemlerinden sonra Microsoft 365 testlerini yapın.
6. ERP Excel Seç ile ARSAN_AI_ERP_v1.0.xlsm dosyasını seçin.
7. Ajan Analizi ve Yedekle işlemlerini test edin.

Not: Proje `net10.0-windows` hedefiyle .NET 10 SDK kullanılarak derlenebilir. Gerçek EXE üretimi bilgisayarınızdaki .NET 10 SDK ile EXE_OLUSTUR.cmd tarafından yapılır.
